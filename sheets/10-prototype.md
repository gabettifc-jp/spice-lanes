**これは草案。承認されていない。**`gamedev/templates/sheets/10-prototype.md` を写して埋めたもの。

> 核（がべ）：**まだ見ぬ世界を探検し、航路を開いて金儲け**
> 本体（がべ）：**行けなかった場所に行けるようになること**

| 問い | 答え |
|---|---|
| **一回で、プレイヤーは何をするか**（動詞ひとつで） | **開く**（出す → 報告 → 載せる／突き返す → 繋ぐ、までを一回とする） |
| **一回は何秒か。**待ち・本体・返しに分けて | 待ち **3秒／6秒／10秒**（選んだ距離で三段）<br>本体 **判断のあいだ**（目安3秒）<br>返し **1.5秒**（黒が剥がれる0.4秒＋街が立つ0.3秒＋線が伸びる0.8秒） |
| **一回の中に、判断はあるか** | **二つ在る。**<br>① **どこへ、どこまで出すか**（方角8つ×距離3段）<br>② **その位置で載せるか、突き返すか**<br>〔**三つめが未決**〕繋ぐ相手を自分で選ぶか、自動で結ばれるか |
| **次に何をすべきかを、どれだけ前に、どんな形で伝えるか** | 帰還の **1秒前**に、船が画面の端に見え始める。<br>**引く前に予想収益は出さない**（相場に合わせる。理由は下） |
| **成功したとき、何が返るか。どこに出るか** | **操作した場所そのもの。**黒が剥がれて街が立つ。<br>そこから既知の街へ線が伸び、金が増え始める |
| **失敗したとき、何が返るか** | 突き返し＝失敗ではない。**街は見えたまま、輪郭が崩れて位置が確定しない。**<br>払ったもの（その航海ぶんの時間）が見える |
| **返しが何も出ない入力が在るか** | **要点検。**突き返しを無音・無反応にすると<br>`ideas.md`「いちばん重い罰を、いちばん静かに出してはいけない」を踏む |
| **許容の幅は何段階で、どれだけか** | 判定ゲームではないので幅は無い。代わりに**提督の測り違い ±15%**（つまみ）。<br>これが突き返しの意味を作る |
| **もう一回やりたくなる理由は、一回の中に在るか** | **賭けている所。**「黒が剥がれて街が立つ」が一回の中の報酬になるか。<br>金は外にあるので、この段では確かめられない |
| **何回繰り返したら飽きるか** | 触って数える |

## 儲けの規則（がべ決・両方乗せる）

    売上 = 産物の価値 × 直線距離 × 地域倍率
    コスト = 航路距離 × 単価
    利益 = 売上 − コスト

| つまみ | 仮の値 | 何のためか |
|---|---|---|
| 産物の価値 | 3段（10／25／60） | 街ごとに一種類 |
| 地域倍率（同じ地域） | 1.0 | 地域内で繋いでも儲からない |
| 地域倍率（隣の地域） | 1.6 | 地域をまたぐ意味 |
| 地域倍率（遠い地域） | 2.4 | さらに先へ行く意味 |
| 航路の単価 | 仮 | **直線距離と航路距離の差**が採算を分ける |
| 提督の測り違い | ±15% | 突き返しの意味 |

**直線距離で売上、航路距離でコスト。**だから「遠いのに、まっすぐ結べる二点」を探すことが儲けになり、
**海の形＝自分が載せた地図の形が、そのまま採算を変える。**

## この段で作らないもの

経済（価格の変動・需給）／進行／転生／副産物／依頼／複数の産物の組み合わせ／保存。
**海に地域が二つか三つ、街が数個、出して、載せて、繋ぐ。それだけ。**

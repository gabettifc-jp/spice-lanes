# 10 一回（プロトタイプ）── spice-lanes

**このシートだけ、いちばん先に埋める。**（`gamedev/flow.md` 段階2-b）

> 核（がべ）：**まだ見ぬ世界を探検し、航路を開いて金儲け**
> 本体（がべ）：**行けなかった場所に行けるようになること**

## 一回＝1ターン

    ① 探検が終わり、黒が剥がれて街が出る（特産品と効果が一行で出る）
    ② 前に繋いだ航路の収入が入る
    ③ 街を繋ぐ        ← 判断。金を使う。**繋いだ特産品の効果が点く**
    ④ 探索に出す      ← 判断。港からピンを立てて線を引く。**引いた長さぶん金を使う**
                      **押すとターンが進む。出さずにスキップもできる**
                      **途中で大地を見つけたら、そこで引き返す**（一回で最大一つ）
                      **払うのは走った分だけ**
    ①へ

**残りターン・取り立ての額・所持金は、常に画面にある**（決定19）。

**Nターン後に取り立てが来る。足りなければ負け**（2-b では一回目だけ）。

**④と⑤は同じ財布から払う。**いま繋げば今すぐ収入が増える。
いま遠くへ出せばもっと太い航路が開くが、その分いまの収入は増えない。

| 問い | 答え |
|---|---|
| **一回で、プレイヤーは何をするか**（動詞ひとつで） | **繋ぐ**（⑤の「出す」はターンを終える行為） |
| **一回は何秒か。**待ち・本体・返しに分けて | 待ち **0秒**（**ターン制。待ち時間を作らない**）<br>本体 **判断のあいだ**（目安8秒＝収入を見る2秒＋繋ぐ相手を選ぶ4秒＋出す先を選ぶ2秒）<br>返し **2.2秒**（収入1.0秒＋線が伸びる0.8秒＋次の①で黒が剥がれる0.4秒） |
| **一回の中に、判断はあるか。**何と何のどちらを選ぶか | **二つ在る。同じ財布を取り合う。**<br>③ **どの街とどの街を繋ぐか**（＝いま稼ぐ／**どの効果を点けるか**）<br>④ **探索の線をどこまで引くか。出さずにスキップするか**（＝先へ行く／貯める）<br>**長く引くほど高いが、当たれば途中で帰ってくる** |
| **次に何をすべきかを、どれだけ前に、どんな形で伝えるか** | ピンを置くたびに**見込みの費用が伸びる**（払う額は見せる）。<br>**引き返したら、走った分だけ引かれる。**<br>**その先に何があるかは見せない。**<br>③で二つの街を選んだ時点で、**その航路の毎ターンの収入を出す**（決定14）。<br>**残りターン・取り立ての額・所持金は常に出ている**（決定19） |
| **成功したとき、何が返るか。どこに出るか** | **操作した場所そのもの。**<br>③ 二つの街のあいだに線が伸び、太さで儲けが出る。**特産品の効果が点く**<br>① 当たった場所を中心に、**視界の半径だけ黒が剥がれて**街が立つ。**その特産品の効果が一行で出る** |
| **失敗したとき、何が返るか。成功と何が違うか** | **失敗は一つだけ。取り立てに足りないこと。**<br>**スコアが出て、リトライと終了**（決定21・仮）。**何も残さない**（決定20・仮）。<br>ただし**負けは前から見えている**（決定19） |
| **返しが何も出ない入力が在るか** | **無い。**払えないものは灰色になり、**それでも押せて、押した対象そのものが赤くなって足りない額が出る**（決定18） |
| **許容の幅は何段階で、どれだけか** | **無い。**判定のあるゲームではない |
| **もう一回やりたくなる理由は、一回の中に在るか、外に在るか** | **両方に賭けている。**<br>内＝黒が剥がれて街が立つこと<br>外＝次のターンに入る収入（**外はこの段では確かめられない**） |
| **何回繰り返したら飽きるか** | 触って数える。<br>**同時に「スキップを何ターン連打したか」も数える**（連打が最適なら判断が消えている） |

### 毎ターンの収入

    航路1本の収入 = 産物の価値 × 直線距離 × 地域倍率 × 効果 − 航路距離 × 単価
    そのターンの収入 = 開いている航路すべての合計

**効果は、その特産品が航路で繋がっているときだけ効く**（決定16）。
効果の型は四つ ── 太い／他に効く／探検に効く／生む（決定15）。

**直線距離で売上、航路距離でコスト。**だから「遠いのに、まっすぐ結べる二点」を探すことが儲けになり、
**海の形＝自分が開いた地図の形が、そのまま採算を変える。**

## この段で作らないもの

価格の変動・需給／進行／転生／依頼／保存／**二回目以降の取り立て**。
**副産物は「作らないもの」から外した** ── 効果の型の一つ（生む）になったため。
**海に地域が二つか三つ、街が数個、繋いで、出して、収入が入る。それだけ。**

# 10 一回（プロトタイプ）── spice-lanes

**このシートだけ、いちばん先に埋める。**（`gamedev/flow.md` 段階2-b）

> 核（がべ）：**まだ見ぬ世界を探検し、航路を開いて金儲け**
> 本体（がべ）：**行けなかった場所に行けるようになること**

## 一回＝1ターン

    ① 探検の結果を聞く
    ② 地図と都市が出る
    ③ 前に繋いだ航路の収入が入る
    ④ 街を繋ぐ        ← 判断。金を使う
    ⑤ 探索に出す      ← 判断。金を使う。**押すとターンが進む**
                      **出さずにスキップもできる**（ターンだけ進む）
    ①へ

**Nターン後に取り立てが来る。足りなければ負け**（2-b では一回目だけ）。

**④と⑤は同じ財布から払う。**いま繋げば今すぐ収入が増える。
いま遠くへ出せばもっと太い航路が開くが、その分いまの収入は増えない。

---

| 問い | 答え |
|---|---|
| **一回で、プレイヤーは何をするか**（動詞ひとつで） | **繋ぐ**（⑤の「出す」はターンを終える行為） |
| **一回は何秒か。**待ち・本体・返しに分けて | 待ち **0秒**（**ターン制。待ち時間を作らない**）<br>本体 **判断のあいだ**（目安8秒＝収入を見る2秒＋繋ぐ相手を選ぶ4秒＋出す先を選ぶ2秒）<br>返し **2.2秒**（収入1.0秒＋線が伸びる0.8秒＋次の①で黒が剥がれる0.4秒） |
| **一回の中に、判断はあるか。**何と何のどちらを選ぶか | **二つ在る。同じ財布を取り合う。**<br>④ **どの街とどの街を繋ぐか**（＝いま稼ぐ）<br>⑤ **どこへ、どこまで出すか。出さずにスキップするか**（＝先へ行く／貯める） |
| **次に何をすべきかを、どれだけ前に、どんな形で伝えるか** | ⑤の出す先は**距離ごとに費用を出す**（払う額は見せる）。<br>**その先に何があるかは見せない。**<br>④で二つの街を選んだ時点で、**その航路の毎ターンの収入を出す**（決定14） |
| **成功したとき、何が返るか。どこに出るか** | **操作した場所そのもの。**<br>④ 二つの街のあいだに線が伸び、太さで儲けが出る<br>① 黒が剥がれて街が立つ |
| **失敗したとき、何が返るか。成功と何が違うか** | **失敗は一つだけ。取り立てに足りないこと。**そこで終わる。<br>返しの中身は決めていない〔未決F〕。<br>小さいほうの「できない」＝金が足りないのに押したとき〔未決E〕 |
| **返しが何も出ない入力が在るか** | **金が足りないのに押したとき。**<br>ここを無音にすると `gamedev/ideas.md`<br>「いちばん重い罰を、いちばん静かに出してはいけない」を踏む |
| **許容の幅は何段階で、どれだけか** | **無い。**判定のあるゲームではない |
| **もう一回やりたくなる理由は、一回の中に在るか、外に在るか** | **両方に賭けている。**<br>内＝黒が剥がれて街が立つこと<br>外＝次のターンに入る収入（**外はこの段では確かめられない**） |
| **何回繰り返したら飽きるか** | 触って数える。<br>**同時に「スキップを何ターン連打したか」も数える**（連打が最適なら判断が消えている） |

## つまみ（値は仮。全部外に出す）

| つまみ | 仮の値 |
|---|---|
| 初期資金 | 仮 |
| 探索の費用（距離3段） | 近／中／遠 |
| 航路を開く費用 | 仮 |
| 産物の価値 | 3段（10／25／60） |
| 地域倍率（同じ／隣／遠い） | 1.0／1.6／2.4 |
| 航路の単価（コスト側） | 仮 |
| **取り立てまでのターン数** | 仮 |
| **取り立ての額** | 仮 |

### 毎ターンの収入

    航路1本の収入 = 産物の価値 × 直線距離 × 地域倍率 − 航路距離 × 単価
    そのターンの収入 = 開いている航路すべての合計

**直線距離で売上、航路距離でコスト。**だから「遠いのに、まっすぐ結べる二点」を探すことが儲けになり、
**海の形＝自分が開いた地図の形が、そのまま採算を変える。**

## この段で作らないもの

価格の変動・需給／進行／転生／副産物／依頼／保存／複数の産物の組み合わせ／**二回目以降の取り立て**。
**海に地域が二つか三つ、街が数個、繋いで、出して、収入が入る。それだけ。**

## 抜ける条件

**「もう一回やりたい」になること。**ならなければ、一回を直すか、核から作り直す。
**通しの問いを埋めて誤魔化さない。**

# spice-lanes

**まだ見ぬ世界を探検し、航路を開いて金儲け。**

`gamedev` の手順で作る二本目。作法は `gamedev/CLAUDE.md` と `gamedev/flow.md`。

| 置き場 | 何が入るか |
|---|---|
| `CLAUDE.md` | このゲームにしか効かない作法 |
| `spec.md` | 仕様の正本（**まだ空。段階2-bを抜けてから書く**） |
| `decisions.md` | 決めたことの記録。四行の型 |
| `sheets/10-prototype.md` | **いま埋めている一枚。**一回（プロトタイプ）の10問 |
| `checklist.md` `prompt.md` `check.md` | ひな形の写し |

## いまどこにいるか

**段階2-b。**一回だけ作って触る段。**まだ何も実装していない。**
